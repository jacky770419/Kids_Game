# 新故事寫稿規則（第二批起，2026-11-13 使用者定）

給學齡前小孩（3～5 歲）的有聲繪本，之後用 ElevenLabs 多角色對話 TTS 錄成中文版和英文版，再請 Codex 照 scene／act 畫插圖。

## 檔案格式
一本一檔：`tools/tts/stories-new/<id>.json`（UTF-8、縮排 1、ensure_ascii=False）。先讀同資料夾已經寫好的 `cinderella.json`、`red-hood.json` 當範例（第一批的標籤太長，新規則見下面）。**不要改其他故事檔、`_cast.json`、`tools/tts/stories.json`。**

```
{
  "id": "...", "title": "中文書名", "title_en": "English Title", "size": "長|中|短",
  "roles": { "<who>": "聲音形象（年紀、個性、口氣），一句話", ... },
  "cast": { "<who>": {"find": "...", "en": "..."}, ... },
  "polyphones": [ {"char": "長", "where": "第3頁『長大』", "read": "zhǎng"} ],
  "pages": [ { "scene": "...", "act": "...", "lines": [ {"who": "旁白", "text": "中文", "en": "English"}, {"who": "角色", "tag": "happy", "text": "...", "en": "..."} ] } ]
}
```
- `who`：旁白一律叫「旁白」；角色名用簡短中文，全書同名。
- `text` 中文、`en` 英文：每句都要有，中英句數與順序一模一樣。
- `scene`：地點與畫面背景（具體到畫家能直接畫）。`act`：這頁誰在做什麼、表情。寫清楚到畫插圖的人不用回頭讀故事；同一個角色的外型（衣服顏色、髮型）全書一致，第一次出場的 act 寫清楚。
- `cast`：每個角色（旁白除外）從下面的聲音表挑一個，寫 `find` 和 `en`（照抄表上的字）。同一頁裡兩個角色不要用同一個聲音；一本裡盡量不重複。

## 篇幅（含標點算字數，只算 text）
- 長篇：14～16 頁，中文約 950～1,050 字
- 中篇：10～12 頁，中文約 550～650 字
- 短篇：8 頁，中文約 320～380 字
每頁 2～5 句。點數是照送出的字元扣的，寫多了就是錄少幾本，請守住上限。

## 語氣標籤 tag（很重要，標籤也算錢）
- **旁白不加 tag**（整句沒有 tag 欄位）。
- 角色的 tag 只寫 **1～2 個英文情緒詞**：happy、sad、scared、angry、sleepy、excited、gentle、proud、surprised、whispering、shouting、laughing、crying 這類。
- **不要寫動作或描述**（例如 "fanning himself"、"teeth chattering"、"sly, sweet voice"）：實測會讓 TTS 重複念整句。
- 語氣跟上一句一樣、或很平常的台詞，可以不加 tag。

## 寫法
- 老故事用自己的話重寫成溫和版（寫法重點見各本），不抄現代繪本或迪士尼的台詞、情節、角色名。科學故事是原創，概念要對，用小孩懂的說法。
- 句子短（中文一句多半 15 字內），用字簡單，多重複句，多對話，小孩可以跟著念。
- 中文用台灣用語。盡量避開破音字（長、覺、重、還、樂、種、數、調、藏、轉、差、落、背、只、為、得、空、好〔動詞〕、更…）；避不開的記在 `polyphones`（了、著、的、地、都、和 不用記）。
- 實測會念錯的寫法，避開：
  - 疊字形容詞（「藍藍的」被念成三聲「懶懶的」），改用「藍色的」「很藍的」。
  - 冷門擬聲字（「嘩啦啦」被念成「哇啦啦」），擬聲詞用常見的：滴答、咚咚、轟隆、呼呼、汪汪、喵。
  - 句子裡同一個詞連著疊兩次以上，模型容易多念一次；要疊就中間加標點（「好熱，好熱！」）。
  - 動物叫聲「呱」「啾」實測會被念成「哇」或被吞掉，不要用；鴨子、小鳥直接說話就好。
  - 一連串單字的口訣（「水、金、地、火…」）念得太快，聽不清楚，改用完整詞（「水星、金星…」）。
  - 角色名字避開容易混的音：「宇」被聽成「呂」。英文名字用常見的英文名。
  - 「哈囉」會被念成英文 hello，打招呼用「嗨」或「你好」。
  - 「傍晚」台灣念 bāng，TTS 會念 bàng，改說「晚上」「太陽要下山了」。
  - 冷門字（卵、雉、靛）容易念錯：「卵」實測被念成「軟」，改用「蛋」。
- 英文是簡單自然的繪本英文，不是逐字翻譯，但每句意思對得上。
- 標點：中文全形，英文一般標點。不要破折號、括號；省略號少用。

## 完成後
用 Python 檢查：JSON 能讀；每句有 who／text／en；旁白沒有 tag；角色 tag 不超過 2 個詞；每個角色都在 roles 和 cast；cast 的值都出自上表；頁數與字數在範圍內。印出每本的頁數、中文字數、英文字元數、每個角色的句數，回報時一起附上，還有破音字和不確定的地方。不要回貼整份稿。
