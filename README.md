# 小小遊樂園

給 5 歲小孩在 iPad 上玩的網頁遊戲，純前端、不需要安裝、離線也能玩。

## 玩法

- 🧩 **拼圖**：三種難度（2×2 / 3×3 / 4×4），觸控拖曳拼片、自動吸附定位
- 🎨 **著色**：先在縮圖牆選一張圖（共 43 張），進入後整個左邊都是紙、右邊是木紋工具列——
  工具（填滿 / 粗筆 / 細筆 / 水彩 / 潑墨 / 亮粉筆）、56 色色盤 + 6 種花紋顏料、橡皮擦、復原、全部清除，
  也可以上傳自己的照片自動轉成線條畫稿（上傳的本來就是黑線白底的線稿時會直接沿用線條，不做邊緣偵測）。**紙是滿版的**，線稿以外的空白處一樣可以畫背景
- 💾 **接著畫**：畫到一半直接關掉也沒關係，下次點同一張圖會接續上次的進度（縮圖右下角有 🖍️ 記號）
- 🖼️ **我的作品**：按 📷 存起來的成品會收進選圖畫面上方的「我的作品」，隨時可以打開來看或刪掉
- 🐻 **著色圖分五個系列**：內建手繪 9 張、城堡與公主 11 張（棒棒糖城堡、綿綿雲城堡、花花小公主、捲捲髮公主、
  南瓜小馬車、彩虹獨角獸、公主的城堡、閃亮皇冠、城堡前的公主、城堡前的小公主、公主與小狗）、動物 12 隻、水果甜點 10 張、場景 1 張（公主與柴犬在草地）。
  場景系列是點陣線稿（`assets/lineart/`，原圖在 `assets/lineart-src/`，用 `tools/make_stencil.py` 轉檔），
  一整張有兩百多個封閉區，適合用 Apple Pencil 點小區塊。拼圖另有 12 隻 Kenney 動物
- 🎵 背景音樂是三首開源曲目輪播（換頁會接著播），音效用 Kenney 的 CC0 音檔；素材來源與授權見 [assets/CREDITS.md](assets/CREDITS.md)

## 在 iPad 上使用

用 Safari 打開這個網站的網址，點分享鈕 →「加入主畫面」，就會變成一個全螢幕的 App 圖示。

橫向、直向都可以用；轉向時畫到一半的內容會留著（畫在紙面最外緣的背景筆畫會被裁掉）。
畫到一半的進度與作品集存在瀏覽器的 IndexedDB 裡，換裝置或清掉網站資料就會不見。

## 開發

純 HTML / CSS / 原生 JavaScript，沒有建置流程，直接用任何靜態伺服器打開即可，例如：

```bash
python -m http.server 8080
```
