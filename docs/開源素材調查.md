## 各來源授權摘要

- **incompetech**：CC BY 4.0，可商用、可再散布，必須以官方三行格式標註。
- **OpenGameArt**：逐條目授權；CC0 條目免標註。⚠ CC BY／CC BY-SA 條目禁止在 DRM 平台（如 App Store）散布——純網頁不受影響，日後若包成 iOS App 要注意，所以優先挑 CC0。
- **Kenney.nl**：全站 CC0，免標註（「appreciated but not mandatory」）。最安全。
- **Free Music Archive**：平台，逐曲授權，NC／ND 一律排除；下載須登入。
- **Freesound**：CC0／CC BY 可用，CC BY-NC 不可；下載須註冊登入。
- **Openclipart**：全站 CC0（FAQ：「every time an artist uploads」）。
- **FreeSVG.org**：全站 CC0，頁尾明文允許商用與再散布。
- **Wikimedia Commons**：逐檔看授權模板；CC BY-SA 會傳染。
- **Twemoji**：CC BY 4.0，README／頁尾／原始碼註明任一即可。
- **OpenMoji**：CC BY-SA 4.0（從 GitHub LICENSE.txt 確認，不是常被誤傳的 CC BY）。
- **Pixabay**：免標註，但禁止「Standalone」散布（未經創作加工、實質同形態）與大量系統性複製。把原始 MP3 放進公開 repo 字面上落在禁止區。**不建議放進公開 repo**。
- **Freepik**：免費授權需標註、禁止再散布、只能當次要元素。**強烈不建議**。
- **SVG Repo**：預設 CC0 但逐 collection 不同（MIT／GPL／CC BY 皆有）；授權頁連續 429 未能親驗，建議略過。

## 整合時的注意事項

1. **iPad Safari 不支援 OGG**：Kenney Interface Sounds 是純 OGG，一律轉 MP3 或 M4A（AAC）。轉檔合法。
2. **incompetech MP3 是 320 kbps，單曲 2.4~8.8 MB**：背景音樂重壓到 96~128 kbps 單聲道（1.5~2.5 MB），音效 64~96 kbps。
3. **音效用 M4A/AAC** 最穩；WAV 太大。
4. **iOS 自動播放限制**：換成音檔播放時要保留 `js/music.js` 現有的「第一次觸控才啟動」流程。
5. **建 `assets/CREDITS.md`**：CC BY 素材（incompetech、Twemoji）必列；CC0 也一併列，方便維護。
6. **著色稿要有封閉面**：Openclipart／FreeSVG 線稿常是 `fill="none"` 純 stroke，點擊填色會失效；挑圖時開檔確認，沒有就手動補閉合面或走既有照片轉線稿工具。這是最容易踩的坑。
7. **viewBox 統一**：現有著色稿 400×400；Kenney 向量／Twemoji 36×36 需 rescale 或包 `<g transform>`。

## 未能確認的項目

1. SVG Repo 授權頁連續 5 次 HTTP 429，條款內容未經原文驗證。
2. Freepik 條款原文：`freepik.com/legal` 導向 `magnific.com` 且回 403；內容取自官方 support 說明的搜尋彙整，但各來源一致，結論不受影響。
3. incompetech 授權頁是 JS 動態產生，靜態抓不到版本號；4.0 來自 FAQ，舊曲在 Wikimedia 標 3.0。
4. incompetech `pieces.json` 查不到本表曲名（推測只含近年新曲），曲目存在性改以 `curl -I` 逐一驗證 HTTP 200。
5. Kenney Music Jingles 與 Interface Sounds 產品頁未列格式；OGG 結論來自 OpenGameArt 鏡像頁。
6. Toy Soldiers／Ice Cream Truck Theme 頁面未標曲長。
7. Kenney 站內搜尋與部分產品頁靠 JS 渲染，WebFetch 取不到；Animal Pack Redux 內容從 OpenGameArt 官方鏡像頁確認。
