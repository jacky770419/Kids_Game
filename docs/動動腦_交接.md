## 使用者定的事

- 孩子是**女兒，用「她」**（有一度傳話誤說用「他」，已作廢）。她喜歡粉色、藍色、動物、公主、畫畫、積木和樂高。
- 配色以粉色＋藍色為主；角色多用動物；可以有公主，但**她是動手解謎的主角**，公主不可以寫成等人幫忙的配角。
- 四間先做；首頁第七扇門；題目語音直接錄、中英都錄，中英文都用旁白 Yui。
- 圖：原本「只用現成」，後來改成可以補畫新圖（Codex 或 Modal 都可以），但要列清單、**開畫前先問**並附張數和花費。他不急，品質優先。
- 錄音：改完裝扮、台詞定案、重新校稿和估點後再問一次；同意後**先試錄兩句**給他聽，可以了才整批錄。
- 不碰 `tools/tts/stories-new/` 和 `_tts/`（別的工作階段在用）；git 只 add 自己的檔，不切分支、不 push；停程序只停自己的 PID。

## 錄音怎麼做（使用者同意之後）

1. `python tools/logic-tts/el_logic.py dry`：再估一次點、看剩多少。
2. `python tools/logic-tts/el_logic.py trial beads.intro1 river.first`：試錄兩句（中英各一份），試聽頁在 `_logic_tts/trial/試聽_動動腦.html`，請使用者聽。
3. 使用者說可以：`python tools/logic-tts/el_logic.py record all`（一句存一次，中斷了重跑會接著錄）。
4. `python tools/logic-tts/el_logic.py build`：轉成單聲道 64k 放進 `assets/logic/audio/<zh|en>/`，重新產生 `js/logic-audio.js`。
5. 把那些 mp3 加進 `sw.js` 的 PRECACHE（`node tools/check_precache.js` 會列出缺哪些），跑 `node tools/check_logic.js`。
6. 我聽不到音檔：請使用者聽，或照 `tts-elevenlabs-workflow` 記憶裡的轉寫核對做法。校稿報告說錄完先聽這幾個字：載、划、捉弄、只、當（當偵探、當老師）、乾、漂亮的輕聲，疊字動詞（猜猜看、試試看、聽聽看、偷偷），`tidy.t.ball` 句尾的「會滾」。
- 聲音：中英文都是故事書旁白 Yui（`tdj_封鈴笙_Yui`），模型和端點跟故事書一樣。改了台詞只會重錄那一句；`build` 只收「跟現在台詞一樣」的檔，沒收的句子網站自動退回系統語音。

## 開發時會用到的

- 預覽伺服器：`python .claude/serve_nosw.py . 8091`（不送 sw.js）。記下自己開的 PID，用完只停那個 PID。
- `logic.html?h=<小屋id>&l=<小關，從 0 起>` 直接開某一關（不念開場）；`&lang=en|both` 換語言；`?all=1` 全部小關都能點。
- 開場（「今天你是公主…」這幾句）每次打開網頁、第一次進那間小屋都會念一次，不存起來。
- 自動操作：`node tools/logic_drive.js tools/logic-tests/<檔>.json --out <資料夾>`（直放的加 `--size 820x1180`）。23 份全跑約 15 分鐘。伺服器同時被好幾個人用的時候會漏接檔案，工具開頁面時會自動重載。
