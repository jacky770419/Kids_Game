## 錄音怎麼做（使用者同意之後）

1. `python tools/logic-tts/el_logic.py dry`：再估一次點、看剩多少。
2. `python tools/logic-tts/el_logic.py trial tidy.ask1 river.first`：試錄兩句（中英各一份），試聽頁在 `_logic_tts/trial/試聽_動動腦.html`，請使用者聽。
3. 他說可以：`python tools/logic-tts/el_logic.py record all`（一句存一次，中斷了重跑會接著錄）。
4. `python tools/logic-tts/el_logic.py build`：轉成單聲道 64k 放進 `assets/logic/audio/<zh|en>/`，重新產生 `js/logic-audio.js`。
5. 把那些 mp3 加進 `sw.js` 的 PRECACHE（`node tools/check_precache.js` 會列出缺哪些），跑 `node tools/check_logic.js`。
6. 我聽不到音檔：請使用者聽，或照 `tts-elevenlabs-workflow` 記憶裡的轉寫核對做法。校稿報告說錄完先聽這幾個字：載、划、捉弄、只、當、乾，疊字動詞（猜猜看、試試看、聽聽看、偷偷），`tidy.t.ball` 句尾的「會滾」。
- 聲音：中英文都是故事書旁白 Yui（`tdj_封鈴笙_Yui`），模型和端點跟故事書一樣。改了台詞只會重錄那一句；`build` 只收「跟現在台詞一樣」的檔，沒收的句子網站自動退回系統語音。
