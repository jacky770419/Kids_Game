## 三、五歲女兒的內容評估

對象：五歲，上寰宇迪士尼美語（DWE），會英文口說、認得部分英文字、不識漢字、認注音、認數字，偏好公主／城堡／獨角獸／動物／甜點。

### 3.1 對抗輪之後還站得住的判斷

- **DWE 不含 phonics**。官方理由是「乳幼兒先大量輸入，等抽象結構理解力發展後再學」，不是前輪說的「非英語環境會混淆」。她很可能「聽得懂、說得出、不會把字母跟聲音連起來」，這是本案最有價值的補位點。
- **單字卡下方的中文對她是純噪音**，換成注音幾乎零成本（`words.js:153` 讀 `item.zh`）。
- **「先學大寫」不足以支撐預設全大寫**：小寫佔實際文本九成以上，Montessori、英國 phonics、手寫教學都先小寫，且先大寫或先小寫幾乎沒有比較研究。DWE 教材字形官方查不到樣張，**翻她家裡的書最準**。
- **三選一對她偏簡單**、18 字玩兩次就摸透。
- **貼紙場景不是「學習價值低」**。Marsh 2018（BJET）：為該年齡設計的開放式創作 app 引發最多種類的遊戲與創造力；結構化與開放式兩者都要，不是二選一。
- Sesame Workshop 的平板指南確有「手腕靠下緣易誤觸」一條，著色頁工具列放右側是對的，直向排版也不要搬到底部。

### 3.2 被推翻、改寫後的判斷

| 前輪主張 | 裁決 |
|---|---|
| 拼圖 5 歲適合 24–48 片，4×4 是入門 | 片數不是難度軸：同樣 48 片 Ravensburger 標 5+、Melissa & Doug 標 3+；觸控吸附版無榫頭辨識，難度另計。裁決：加 5×5／6×6 給她選，用圖片主題（公主城堡）拉黏著度，不拿片數當發展指標 |
| 注音 37 符號分三批、ㄓㄔㄕㄖ／ㄗㄘㄙ最後 | 康軒首冊是綜合教學法，符號順序由課文決定，前輪順序是自創的。裁決：**不自創順序**，先用一張亂序 37 符號表測她認得哪些，「已認得」當第一批鞏固、「不認得」第二批，每批不超過 8 個 |
| Phonics 照 satpin 順序 | 台灣自然發音教材走「短母音→子音→CVC」，satpin 是英國 Jolly Phonics。裁決：兩套都不硬套，**用她已經會說的字做首音分類**（sun／star／strawberry 都是 /s/），字是她的、音是新的，避開順序之爭。播音素不播字母名這條成立 |
| 點點卡不設閃現時間 | quick images 的定義就是閃 2–3 秒後蓋牌，不閃就退化成點數練習。裁決：卡片 2–3 秒後自動蓋起來，但**可以無限次再翻開看**，沒有失敗判定，不違反無壓力原則 |
| 幼兒園不得教注音拼讀 | 法源是幼兒教保及照顧服務實施準則第 13 條，禁的是分科與精熟讀寫算，未點名注音。遊戲化認讀沒有問題 |
| 「ㄅ 玻」呼讀音可當 TTS 的替代 | 不能用：呼讀音自帶ㄛ韻，正是要避免的錯誤念法。**speechSynthesis zh-TW 唸不唸得出單一注音符號查不到實測，要在 iPad 實機測**；唸不出就真人錄 37 個 |
| DWE 全系統約 2,400 字 | 官方從未公佈字彙總量，且教材字彙量不能推她的詞彙量。Talkalong 510 張成立 |

### 3.3 對抗輪指出的最大盲點

前輪用「教材規格」代替「她的能力」，再在上面疊自創順序。**十分鐘的家庭量測比任何網路來源都準**，而且直接是內容設計的輸入：

1. 一張亂序 37 注音符號表，指著念，圈出念不出的。
2. 10 張大寫、10 張小寫字母卡亂序指認；再問「它發什麼聲音」，兩題答案不同代表有字母名沒有音。
3. 數 7 顆東西後問「總共幾顆」，會不會重數（基數原則）。
4. 問「apple 的第一個聲音是什麼」「ball 跟 bear 開頭一不一樣」（首音覺識）。
5. 翻她的 Sing Along 歌詞本目錄，記下她唱得出的主題，那就是字彙擴充的字表；順便看教材字形是不是正常大小寫。

### 3.4 裁決後的優先序

| 序 | 項目 | 為什麼在這個位置 | 沿用度 |
|---|---|---|---|
| 0 | 上面的十分鐘量測 | 決定 3、5、6 的內容，不寫程式 | — |
| 1 | **單字頁小改四件**：中文換注音（`words.json` 加 `bpmf`）、Aa 字形切換（預設小寫，量測後可調）、只聽不看字模式、選項 3→4 可選；**加上**著色頁選色時唸顏色英文、拼圖拼完唸動物英文 | 半天到一天，全吃現有機制，同時修掉三個已確認的問題 | 100% |
| 2 | **字彙擴充 18→60–80 字＋主題頁籤**（沿用著色頁的換行頁籤） | 純資料，字表來自她的歌詞本而不是網路推測；圖片是唯一成本 | 程式改 filter 一處 |
| 3 | **貼紙場景**：城堡／海邊／森林背景，拖公主、獨角獸、甜點貼紙，貼上時唸英文，存進作品集 | 對抗輪把它從第六升上來：開放式創作有實證支持，且命中她全部偏好，`stamps-data.js`＋著色畫布＋IndexedDB 作品集全現成 | 高 |
| 4 | **注音符號認讀**（配對＋翻牌） | 她唯一看得懂的中文，有限集合 37 個。前置：iPad 實測 TTS 唸單一符號；不行就錄音 | 翻牌配對機制原樣 |
| 5 | **Phonics 首音**（用她會的字分組） | 唯一補 DWE 結構缺口的項目；音素必須真人錄 | 配對機制原樣，圖要依首音重挑 |
| 6 | **點點卡**（規則排列、2–3 秒蓋牌可重翻）＋數量配對（水果 SVG 拖進盤子） | 符號↔數量是她的下一階台階 | 三選一版面＋拼圖拖曳 |

### 3.5 不建議做（維持前輪，理由經對抗輪未被推翻）

打字／拼字輸入、混音成詞（首音未建立前）、計時與分數排行、隨機獎勵扭蛋、漢字認讀、手寫筆順自動批改（誤判一次就不玩）、語音辨識評分（要網路、幼兒辨識率低）、時鐘、抽象算式、雙人連線、大段文字說明、主要按鈕放畫面下緣、結合韻與四聲。

- 未認證 GitHub API 每小時 60 次，補搜要錯開或帶 token。
